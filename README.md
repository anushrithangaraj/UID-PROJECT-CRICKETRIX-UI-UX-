# 🏏 Cricketrix - UI/UX Design

This repository contains the UI/UX design mockups for the **Cricketrix App**, a cricket-focused mobile and web application featuring live scores, news, ticket booking, and shopping features.

## 📁 Project Overview

• Designed for both **mobile and desktop** platforms  
• Focused on clean, intuitive, and responsive layouts  
• Consistent use of **color palettes** and **typography**  
• Features designed:  
  - Live Score Dashboard  
  - Cricket News Feed  
  - Cricket Merchandise Store  
  - Match Ticket Booking System  
  - User Profile and Navigation
